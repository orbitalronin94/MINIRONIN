# BOE — legislación consolidada vigente

- API oficial: https://www.boe.es/datosabiertos/api/api.php?lang=es
- Documentación técnica: API de acceso a la colección de Legislación Consolidada, 2 de septiembre de 2025.
- Reutilización: condiciones BOE vigentes desde 28-06-2024; permiten uso comercial/no comercial y obras derivadas, con atribución obligatoria.
- Se excluye Biblioteca Jurídica Digital, expresamente CC BY-NC-ND 4.0, y no se incorporan anuncios BORME ni contenidos de terceros.
- Se descargan únicamente leyes consolidadas no derogadas, no anuladas y no agotadas; por artículo/bloque se selecciona la última versión efectiva a fecha de descarga.
- Cada registro mantiene identificador BOE, URL oficial, ELI, título, fechas, departamento, rango, estado y aviso de que el texto consolidado es meramente informativo.
- Los payloads se publican como assets de release, no en Git; cada batch incluye SHA-256 y manifiesto.
