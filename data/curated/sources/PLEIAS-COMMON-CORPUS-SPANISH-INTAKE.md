# PleIAs Common Corpus — intake español

- Dataset: https://huggingface.co/datasets/PleIAs/common_corpus
- Corpus global: 2.27 trillion tokens; the card says Spanish is one of the languages with more than 10 billion tokens.
- Per-record metadata: identifier, collection, open_type, license, date, title, creator, language and full text.
- Admission: Spanish only; OpenScience, OpenGovernment and OpenSemantic only.
- Rights filter: public domain, PDM, CC0 or CC BY attribution-only. Excludes SA, NC, ND and unknown licenses.
- First batch: 10 Parquet shards, each about 430 MB; actual admitted row counts are generated by the workflow.
- Assets are stored in a versioned GitHub release, not Git history; the unified build downloads only audited JSONL shards.
- OpenCulture, OpenWeb and OpenSource are excluded in this first batch to reduce overlap with existing Spanish-PD books, Wikimedia and code corpora.
