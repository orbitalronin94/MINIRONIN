# Marco de privacidad: gestionar riesgos para las personas

**Fuente:** NIST Privacy Framework — https://www.nist.gov/privacy-framework  
**Estado:** marco voluntario; consultar la página oficial para revisiones vigentes. Síntesis original.

La privacidad no se reduce a confidencialidad ni a evitar filtraciones. El tratamiento de datos puede producir problemas incluso cuando es técnicamente seguro: vigilancia inesperada, decisiones injustas, pérdida de autonomía o usos secundarios incompatibles con las expectativas.

Un marco de privacidad ayuda a identificar datos y operaciones, gobernar responsabilidades, controlar tratamientos, comunicar prácticas y proteger información. La organización debe entender qué recoge, para qué, con quién lo comparte, cuánto tiempo lo conserva y qué efectos puede producir.

La minimización reduce exposición y complejidad. La finalidad debe ser concreta y compatible con el uso real. Reutilizar datos para nuevos objetivos requiere evaluación independiente.

La privacidad debe considerarse desde el diseño. Evaluaciones de impacto, controles de acceso, retención limitada, transparencia y mecanismos para ejercer derechos pueden ayudar. El marco no sustituye obligaciones legales: el cumplimiento depende de jurisdicción y contexto.

**Conceptos:** minimización, finalidad, gobernanza, transparencia, impacto, ciclo de vida de datos.
